# cnn-image-classification
Convolutional Neural Networks for Image Classification

A project on using convolutional neural networks (CNNs) for image classification.

## Project Overview

This project explores how convolutional neural networks can be used to classify images into different categories.

## Notebook

The main project is available in the Jupyter/Google Colab notebook:

`cnn-image-classification.ipynb`

## Technologies

- Python
- Google Colab
- TensorFlow / Keras
- NumPy
- Matplotlib
